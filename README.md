«Данное приложение реализовано на чистом JavaScript (Vanilla JS) без использования UI-библиотек. Это решение принято намеренно, чтобы продемонстрировать уверенное владение нативным DOM API, понимание принципов работы SPA-роутинга через History API и механизмов кэширования данных в LocalStorage.

Архитектура приложения (разделение на Service и UI-модули) спроектирована так, чтобы ее можно было легко перенести на React. В частности, логика CurrencyService может быть обернута в кастомный хук useCurrency, а ручное управление состоянием — заменено на useState и Context API. При необходимости компоненты могут быть стилизованы с помощью CSS-in-JS или TailwindCSS».
