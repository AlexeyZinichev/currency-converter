# Конвертер валют

Одностраничное приложение (SPA) для конвертации валют, реализованное на чистом JavaScript (Vanilla JS).

## Функционал
- Конвертация по текстовому запросу (например: `15 usd in rub`).
- Отображение актуальных курсов валют.
- Выбор и настройка базовой валюты.
- Кэширование данных в LocalStorage для мгновенной работы.

## Технологии
HTML, CSS (Grid, Flexbox, Animations), JavaScript (ES6+, Fetch API, History API, LocalStorage).

## Запуск
1. Откройте файл `index.html` в браузере.
2. Для корректной работы API рекомендуется запускать через локальный сервер (например, расширение Live Server в VS Code).
